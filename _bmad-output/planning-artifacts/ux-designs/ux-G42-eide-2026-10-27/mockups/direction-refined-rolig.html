Rolig notatbok – forfinet

Refined calm notebook · accent #1D5C63 · light mode only

This direction keeps Rolig notatbok as the foundation and applies the eight refinements the user chose. Where each one is visible:

  1. Rolig foundation kept — warm paper #F7F3EA, deep teal #1D5C63, 17px/1.65 calm system type and simple underlined result tabs (all frames; tabs in Frames 1–2).
  2. Centred, minimal flashcard — single bordered card, no shadow, centred counter, term and controls (Frame 1).
  3. Centred term, left-aligned answer — "Sikkerhetslager" is centred; the answer block is left-aligned and capped at 65ch inside the card (Frame 1; quiz answers also left-aligned in Frame 2).
  4. Borrowed from Vennlig — (a) file chip with file icon, name and "PDF · 2,4 MB", flat with a 1px border instead of a shadow (Frames 1, 3, 4); (b) stronger header: surface band, 24px bold brand, 30px teal logo and 2px teal bottom rule (all frames).
  5. Comfortable targets + strong focus — buttons, tabs and inputs are min 44px tall; focus = 3px solid #1D5C63 outline, 2px offset (6.86:1 on paper). Shown on "Skjul svar" (Frame 1) and the "Quiz (6)" tab (Frame 2).
  6. Less vertical space above results — header 12px padding (was 40px top + 28/28 around rule), notices 8px apart, upload bar 12px padding and 14px below (was 20/24 and 40px below); by estimate the tabs start about 150–190px higher than in the foundation (Frame 1).
  7. Compact notices — icon + text, 7px/14px padding, 15px type, 3px left rule in the ink colour plus distinct tint; meaning never carried by colour alone (Frames 1–3, 5).
  8. Light mode only — no dark-mode styles are defined.
