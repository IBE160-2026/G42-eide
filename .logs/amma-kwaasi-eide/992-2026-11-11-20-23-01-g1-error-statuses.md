### Result
- **Developer decisions:**
  - **Option A:** unknown routes return 404 `not_found`, and unsupported methods return 405 `method_not_allowed` with the `Allow` header, both in the common error format with CORS headers.
  - **P1:** CORS preflight replies keep Starlette's defaults and are an explicit exception to the error format; a plain `OPTIONS` is an unsupported method.
  - **H1:** no route accepts `HEAD`, so it gets 405 with `Allow` (or 404 for an unknown path), with headers only and no body.
  - **Messages:** `Adressen finnes ikke.` and `Metoden støttes ikke for denne adressen.`
  - **Story 1.14:** no new query-string requirement; the existing AD-20 "ignores any query input" stays.
