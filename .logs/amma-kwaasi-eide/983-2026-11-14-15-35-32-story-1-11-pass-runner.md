### Result
- **Spec commit:** `0f4902400272a44014abace534c6654963b58126` ("docs: approve Story 1.11 specification"), holding **34 acceptance scenarios**.
- **Implementation commit:** `e359f67d8afc71b5d99a562b7d6af75291cc8612` ("feat: implement Story 1.11 six-stage pass runner"): 7 files, 1,202 insertions, local only.
  - `backend/app/pipeline/pass_runner.py` (new):
    - **`PassRunner.run_pass`:**
      - checks `source` strictly before the lock;
      - acquires the guard non-blockingly, raising the busy `PassFailure("generation_in_progress")` **outside** the `try`, so a refused call never releases the holder's lock;
      - runs validate_bytes → extract_document → build_request → stage 4 → validate_output → `respond`;
      - releases the lock in `finally`.
    - **Stage 4 `_generate`:**
      - accepts only an exact built-in `str` code from `CONNECTOR_ERROR_CODES`, read with `getattr`, and deletes its temporary;
      - raises the `PassFailure`, or a fixed-message `TypeError` for an invalid code, after the `except` clause;
      - rejects a non-`ConnectorReply` with a fixed-message `TypeError`;
      - uses no `assert`.
    - **Stage 6 `respond`:** accepts only `ValidatedResults` and builds the envelope.
    - **No cost gate:** no `count_input_tokens`.
  - `backend/app/pipeline/pass_guard.py` (new): `PassGuard` with `try_acquire()` (`acquire(blocking=False)`), `release()` and `locked()`.
  - `backend/app/contracts/responses.py` (new): a frozen `GenerationResponse(mode, results: InstanceOf[ValidatedResults], skipped_pages)`, with JSON arrays in JSON mode.
  - `backend/app/api/errors.py` (+9): the `PassFailure` handler, which reuses `build_error_response`. It gives the AD-11 envelope, `HTTP_STATUS` codes (409, 400, 413, 422, 429, 502, 503), `limit` only for `file_too_large`, and one code-only log line. Nothing else in the file changed.
  - `backend/app/application.py` (+3): `application.state.pass_guard = PassGuard()`, one per app instance.
  - `backend/tests/_pdf.py` (new): a standalone PDF builder.
  - `backend/tests/test_pass_runner.py` (new): **74 tests** covering every new-behaviour matrix row. The two regression rows are covered by rerunning the existing suite.
- **Independent code review:** production code passed all 19 checks. The test file needed corrections:

  - **R2:** "never waits" was shown only by timing. **Fixed:** a never-blocking spy lock records every `acquire` and fails at teardown on any blocking or timed call.
  - **R3:** wider privacy coverage: invalid codes including a malicious `str` subclass, invalid replies, unexpected errors, stage 6 and busy refusal, and HTTP logging with a chained secret.
